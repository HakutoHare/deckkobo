# デッキ工房

遊戯王OCGのデッキと所持カードを管理し、足りないカードを割り出すスマホ向けのWebアプリです。
ホーム画面に追加して使う PWA で、iPhone・Android の両方で使えます。

**公開URL**：https://hakutohare.github.io/deckkobo/

## 特長

- URL を開いてホーム画面に追加するだけで使えます。インストール作業は不要です
- 初回の読み込み後は、オフラインでもすべての機能が使えます
- データは端末内にのみ保存します。写真・連絡先などには触れず、権限の要求もしません
- アップデートしても、デッキなどのデータはそのまま残ります

## 主な機能

- **デッキ**：デッキの作成・編集（メイン／EX／サイド）。カード名か読み仮名で検索できます
  - 遊戯王ニューロンで出力したデッキリスト（PDF）を読み込んで、デッキとして登録できます
  - 同じ用紙を画像にしたもの（PNG・JPEG など）からも読み込めます。文字の読み取りは端末の中で行い、結果は確認画面で直してから登録します
  - デッキのカードをまとめて所持に追加・所持から削除できます（どちらもカードごとに枚数を調整できます）
- **不足カード**：集計対象のデッキに対して、所持枚数で足りないカードを一覧表示します。買ったカードの枚数を選んで、まとめて所持に追加できます
- **所持**：持っているカードと枚数の登録。カード名をタップすると、レア度ごとの枚数も登録できます（デッキの中身からも可。カード名の前に小さな印で表示）
- **設定**：不足カードの数え方の切り替え、バックアップの書き出し・読み込み、更新の確認

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（HTML・CSS・JS を1ファイルに収めています） |
| `cardlist.json` | カード一覧（14,233種） |
| `sw.js` | オフライン用のキャッシュと更新処理。`VERSION` がアプリのバージョンです |
| `manifest.webmanifest` | PWA の設定 |
| `icon-*.png` / `apple-touch-icon.png` | アイコン |
| `lib/` | PDF を読むための部品（[pdf.js](https://github.com/mozilla/pdf.js)、Apache License 2.0）と日本語の文字表 |
| `lib/ocr/` | 画像の文字を読み取る部品（[Tesseract.js](https://github.com/naptha/tesseract.js)、Apache License 2.0）と日本語の学習データ。画像を初めて読み込むときに取得します |

## 更新するとき

1. ファイルを変更したら、`sw.js` の `VERSION` を上げます（上げないと端末側が古いキャッシュのままになります）
2. 新しく追加したファイルがあれば、`sw.js` の `FILES` に加えます
3. `main` ブランチに反映すると、端末は次回起動時か設定画面の「更新を確認」で新しい版に切り替わります

## カードデータについて

- カード名・種別：[mycard/ygopro-database](https://github.com/mycard/ygopro-database)（OCG のみ）
- 読み仮名：[DawnbrandBots/yaml-yugi](https://github.com/DawnbrandBots/yaml-yugi)、遊戯王ニューロン（公式データベース）ほか
